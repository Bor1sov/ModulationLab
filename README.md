# ModulationLab (Node.js + TypeScript)

Порт учебного Python-приложения «Модуляция и синтез сигналов» на Node.js + TypeScript.
Выполняет модуляцию гармонического сигнала меандром (АМ / ЧМ / ФМ), строит спектры,
синтезирует сигнал по обрезанному спектру АМ и демодулирует его детектором огибающей
до формы, похожей на модулирующий меандр. Все графики сохраняются в PNG.

Никакого браузера, Electron или веб-сервера — чистый CLI, аналогичный запуску
Python-скрипта `python main.py`.

---

## Что делает программа

Используя несущую **20 Гц** и меандр **2 Гц**, программа:

1. Строит несущую и модулирующий сигнал (меандр).
2. Выполняет три вида модуляции:
   - **АМ** — амплитудная, глубина 0.6;
   - **ЧМ** — частотная, девиация 20 Гц;
   - **ФМ** — фазовая, сдвиг π/2.
3. Считает ДПФ каждого модулированного сигнала.
4. **Обрезает спектр АМ** до полосы **15–25 Гц** — отсекает и низкие, и высокие
   частоты, оставляя только основную часть (несущую 20 Гц и боковые 18 и 22 Гц).
5. **Синтезирует** сигнал по обрезанному спектру через ОБПФ.
6. **Демодулирует** синтезированный сигнал детектором огибающей:
   - `|synth(t)|` — выпрямление (диодный детектор);
   - ФНЧ Баттерворта 4-го порядка, `cutoff = 10 Гц`, с `filtfilt` — срезает
     высокочастотную «пилу» (2·fc = 40 Гц), оставляет огибающую (2 Гц);
   - нормировка в `[0, 1]`.
   После этого форма сигнала похожа на модулирующий меандр: сохраняется период
   2 Гц, фронты сглажены (т.к. при обрезке 15–25 Гц осталось всего 3 компоненты).
7. Строит **сравнительный график**: огибающая после демодуляции vs исходный меандр.
8. Сохраняет 8 отдельных PNG + сводный PNG 4×3 (12 панелей).

### Зачем детектирование огибающей, а не просто ФНЧ

После обрезки спектра до 15–25 Гц все компоненты синтезированного сигнала лежат
**выше** 10 Гц (18, 20, 22 Гц). Прямой ФНЧ на 10 Гц обнулил бы сигнал целиком.
Поэтому сначала выполняется **выпрямление** `|x|` — оно переносит информацию об
огибающей в низкочастотную область, и только потом применяется ФНЧ, который
оставляет именно огибающую. Это классический «диодный детектор + ФНЧ» из
радиотехники — штатная схема демодуляции АМ.

## Требования

- **Node.js ≥ 18** (проверено на 18 / 20 / 22)
- **npm ≥ 9**
- **Windows / Linux / macOS**
- Для `canvas` при отсутствии prebuilt-бинарника:
  - **Windows**: VS Build Tools с компонентом «Desktop development with C++»;
  - **Linux**: `build-essential libcairo2-dev libpango1.0-dev libjpeg-dev libgif-dev librsvg2-dev`;
  - **macOS**: `xcode-select --install`.

Проверить версию Node:

```bash
node --version
```

## Установка

```bash
git clone <repo-url> modulation-lab-ts
cd modulation-lab-ts
npm install
```

Если `canvas` не устанавливается из prebuilt (бывает на самых свежих Node):

```bash
npm install canvas@^3 --force
```

или установите системные зависимости (см. раздел «Требования»).

## Запуск

По умолчанию: `fs = 1000`, `duration = 1 с` — как в Python-версии.

```bash
npm start
```

С собственными параметрами:

```bash
npm run build
node dist/index.js 2000 2
#                        ^    ^
#                        fs   duration
```

| Аргумент | Тип | По умолчанию | Описание |
|---|---|---|---|
| `fs` | целое > 0 | `1000` | Частота дискретизации, Гц |
| `duration` | число > 0 | `1` | Длительность сигнала, с |

```

├── fm_sig.png                # ЧМ сигнал
├── pm_sig.png                # ФМ сигнал
├── am_spec.png               # Спектр АМ (0–100 Гц)
├── fm_spec.png               # Спектр ЧМ
├── pm_spec.png               # Спектр ФМ
├── am_synth.png              # Сигнал после обрезки спектра (15–25 Гц) + ОБПФ
├── am_filtered_compare.png   # Демодуляция (огибающая) vs исходный меандр
└── all_plots.png             # Сводная фигура 4×3 (12 панелей)
```

`all_plots.png` — аналог окна PyQt5-версии, но в виде одного большого PNG.

В консоль выводится:

```
Запуск: fs=1000, duration=1

```

### Как выглядит сводная фигура 4×3

| # | Панель | Что показывает |
|---|---|---|
| 1 | Несущая (20 Гц) | `sin(2π·20t)` |
| 2 | Меандр (2 Гц) | Модулирующий сигнал |
| 3 | АМ сигнал | `(1 + 0.6·m(t))·sin(2π·20t)` |
| 4 | Спектр АМ | Пики на 18, 20, 22, 14, 26, 10, 30, … |
| 5 | Обрезанный спектр | Только 18, 20, 22 Гц |
| 6 | Синтезированный сигнал | ОБПФ от обрезанного спектра |
| 7 | Огибающая после демодуляции | `\|x\|` → ФНЧ(10 Гц) → нормировка |
| 8 | **Демодуляция vs модулирующий** | Наложение: огибающая ≈ меандр |
| 9 | ЧМ сигнал | Частотная модуляция |
| 10 | Спектр ЧМ | Боковые составляющие ЧМ |
| 11 | ФМ сигнал | Фазовая модуляция |
| 12 | Спектр ФМ | Боковые составляющие ФМ |

Панель 8 — ключевая для отчёта по заданию: на ней видно, что после синтеза и
демодуляции форма сигнала похожа на модулирующий меандр.

## Технические детали

### ДПФ / ОБПФ

Используется прямое ДПФ (`O(n²)`), результат идентичен `numpy.fft.fft` /
`numpy.fft.ifft` с точностью до машинной погрешности. Для `fs=1000, dur=1`
(1000 точек) расчёт занимает доли секунды. При бóльших массивах интерфейс
`dft` / `idftReal` в `spectrum_proc.ts` легко заменить на FFT-библиотеку
(например, `fft.js`) без изменения остального кода.

### Фильтр Баттерворта + `filtfilt`

Реализован каскад из двух биквадов (`Q = 0.5412` и `Q = 1.3066`) с
последующей двусторонней фильтрацией и odd-reflection padding —
математически совпадает с `scipy.signal.butter(4, ...)` +
`scipy.signal.filtfilt`.

### Рендеринг

Графики строятся через `chartjs-node-canvas` (Chart.js 4 → `node-canvas` → PNG).
Сводная фигура собирается вручную: 12 отрендеренных PNG склеиваются в
один `canvas` 1500×1200 через `ctx.drawImage`.

## Возможные проблемы

### `npm error ERESOLVE`

Конфликт peer-зависимостей `chartjs-node-canvas` ↔ `chart.js`.
Версия `chartjs-node-canvas@5.x` официально поддерживает Chart.js 4.x.
Проверьте `package.json`:

```json
"dependencies": {
  "canvas": "^3.0.0",
  "chart.js": "^4.4.1",
  "chartjs-node-canvas": "^5.0.0"
}
```

### `canvas` не ставится

- **Windows**: установите [VS Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/)
  с компонентом «Desktop development with C++».
- **Linux**: `sudo apt install build-essential libcairo2-dev libpango1.0-dev libjpeg-dev libgif-dev librsvg2-dev`
- **macOS**: `xcode-select --install`

### `TS2304: Cannot find name 'HTMLCanvasElement'`

В `tsconfig.json` в поле `lib` обязательно должны быть `"DOM"` и `"DOM.Iterable"`:

```json
"lib": ["ES2020", "DOM", "DOM.Iterable"]
```

### `Module './painter' has errors`

Значит `painter.ts` не скомпилировался. Запустите:

```bash
npx tsc --noEmit
```

и посмотрите первую ошибку — она указывает на конкретную строку в `painter.ts`.

### Старые ошибки после правок

Удалите папку `dist/` и пересоберите:

```bash
# Windows PowerShell
Remove-Item -Recurse -Force dist
# Linux/macOS
rm -rf dist

npx tsc --noEmit
npm run build
```
